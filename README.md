# speedtest

Скрипт замера скорости интернета: последовательно скачивает файл по URL и
считает среднее время запроса, объём и скорость в МБ/с.

## Требования

- Python 3.8+ (проверено на 3.14)
- Только стандартная библиотека — `pip install` не нужен

## Запуск

```bash
python3 speedtest.py
```

По умолчанию: URL `https://asialive.news/test-image`, 10 запросов.

## Параметры

```bash
python3 speedtest.py [URL] [--runs N]
```

| Аргумент | По умолчанию | Описание |
|---|---|---|
| `URL` | `https://asialive.news/test-image` | Адрес файла для загрузки |
| `--runs N` | `10` | Число последовательных запросов (>= 1) |

Примеры:

```bash
python3 speedtest.py --runs 3
python3 speedtest.py https://asialive.news/test-image --runs 20
```

## Вывод

По каждому запросу: размер, время, скорость. Затем итог — успешные запросы,
суммарный объём, среднее время запроса и средняя скорость (МБ/с и Мбит/с).

```
URL: https://asialive.news/test-image
Запросов: 10
------------------------------------------------
#01    3.39 MB    1.24 s     2.74 MB/s
...
------------------------------------------------
Успешных запросов:      10/10
Скачано всего:          33.92 MB
Среднее время запроса:  1.62 s
Средняя скорость:       2.09 MB/s (16.71 Mbit/s)
```

При ошибках сети/HTTP запрос помечается как ошибочный, остальные продолжаются.
Если не удался ни один запрос — код выхода `1`.
